# 우리집 식탁 · Table Mate (PWA)

재료별 요리 그룹, 레시피 상세, 주간 식단, 자동 장보기 목록을 제공하는 한국어 PWA입니다.

## 파일 구성
- `index.html`: 화면과 기능
- `recipes.json`: 60개 레시피와 표준 재료 목록
- `manifest.webmanifest`: 홈 화면 설치 설정
- `sw.js`: 정적 파일 캐시 및 기본 오프라인 지원
- `icon-192.png`, `icon-512.png`: 앱 아이콘

## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. GitHub 저장소의 최상위(root)에 위 파일 6개를 업로드합니다. ZIP 파일 자체만 올리면 앱이 실행되지 않습니다.
3. 저장소에서 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치와 `/(root)`를 지정한 뒤 저장합니다.
5. 몇 분 뒤 `https://사용자이름.github.io/저장소이름/`으로 접속합니다.
6. `index.html`과 `recipes.json`이 같은 폴더에 있어야 합니다.

## iPhone 설치
Safari로 배포 주소를 연 뒤 공유 버튼 → **홈 화면에 추가**를 선택합니다. PWA 설치와 서비스 워커는 HTTPS 환경에서 동작합니다.

## 저장과 개인정보
사용자 재료, 식단, 즐겨찾기, 장보기 체크는 해당 브라우저의 `localStorage`에 저장됩니다. 서버로 전송하지 않습니다. 브라우저 데이터 삭제 또는 기기 변경 전에 별도 백업이 필요하며, 현재 버전은 기기 간 동기화를 지원하지 않습니다.

## 계산 규칙
- 각 레시피의 기본 분량은 4인분입니다.
- 식단에 같은 레시피를 여러 번 넣으면 재료 수량도 횟수만큼 합산합니다.
- 장보기 수량은 `계획 총량 - 보유량`이며 0보다 작은 경우 구매 목록에서 제외합니다.
- 같은 재료 ID는 하나의 표준 단위만 사용합니다. 예: 감자 g, 우유 ml, 달걀 개.
- 레시피 데이터의 재료 ID, 단위, 양수 수량, 레시피 개수를 자동 검증했습니다.

## 음식 안전
이 앱은 가정용 참고 레시피이며 전문 영양·의료 조언이 아닙니다. 재료의 크기, 제품, 기기와 화력에 따라 조리 시간은 달라집니다. 특히 육류·생선·달걀은 안전하게 충분히 익히고, 알레르기 유발 성분은 제품 라벨을 확인하세요.
